# Contributing to QA Sentinel

First off, thank you for taking the time to contribute! 🎉

QA Sentinel is an open-source initiative dedicated to empowering QA engineers with transparent, controllable AI automation.

## Code of Conduct

By participating in this project, you agree to abide by our respectful, inclusive community standards.

## How Can You Contribute?

1. **Reporting Bugs:** File an issue using our bug report template with system logs and Playwright trace files.
2. **Suggesting Enhancements:** Open an issue outlining the user problem, proposed agent behavior, and human governance impact.
3. **Adding Integrations:** We welcome connectors for:
   - Test Management: Jira, TestRail, Zephyr, Xray
   - CI/CD: GitHub Actions, GitLab CI, Jenkins, CircleCI
   - Bug Trackers: Linear, GitHub Issues, Bugzilla

## Development Workflow

1. Fork the repo and create your branch from `main`.
2. Follow standard TypeScript formatting and linting rules.
3. Ensure all agent JSON schemas are strictly validated with Zod.
4. Submit your Pull Request with a clear description and testing evidence.
